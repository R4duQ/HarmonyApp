HARMONY 1.0.1-universal - SPOTIFLAC PENTRU AMBELE ARHITECTURI

Arhiva contine proiectul complet, inclusiv SpotiFLAC, Soulseek si Discovery.
Este un pachet de SURSE, nu un APK. versionCode: 85.
Pastrate: corectiile audio din arhiva ta 1.0.1-audiofix.
Compatibilitate: Android 10+ pe ARM64 sau x86_64, cu sistem Android pe 64 biti.
APK-ul implicit este universal; Android alege automat codul potrivit.
Backendul Go si convertorul FLAC/MP3 sunt incluse pentru ambele arhitecturi.

ACTUALIZARE PE PC
1. Inchide Android Studio daca are proiectul deschis.
2. Extrage CONTINUTUL folderului Harmony din arhiva peste D:\Harmony.
   Fisierul settings.gradle.kts trebuie sa fie in D:\Harmony, nu intr-un
   al doilea subfolder Harmony.
3. Pastreaza local.properties, keystore.properties si cheia de semnare existente.
   SDK-ul tau ramane D:\Android.
4. Pentru instalarea debug folosita anterior, conecteaza telefonul prin USB,
   autorizeaza depanarea si ruleaza:

   D:\Harmony\Instaleaza-Harmony-pe-telefon.cmd

5. Verifica versiunea 1.0.1-universal in Settings sau in informatiile Android.

Daca aplicatia de pe telefon este un RELEASE semnat, foloseste aceeasi cheie
si un build release. In PowerShell:

   cd D:\Harmony
   .\gradlew.bat :app:assembleRelease
   D:\Android\platform-tools\adb.exe install -r .\app\build\outputs\apk\release\app-release.apk

Nu dezinstala aplicatia si nu sterge datele pentru a rezolva o eroare de semnare.
O actualizare trebuie semnata cu cheia versiunii instalate.

NDK: daca Gradle il solicita, instaleaza 29.0.14206865 din SDK Manager >
SDK Tools > NDK (Side by side). Sunt necesare si SDK 35, Build Tools,
CMake 3.22.1 si Java 17. SDK-ul tau ramane D:\Android.
Go si FFmpeg nu trebuie instalate pe telefon sau compilate pe Windows:
componentele necesare SpotiFLAC sunt deja incluse in aceasta arhiva.

RELEASE PENTRU ALTE TELEFOANE
Foloseste APK-ul universal semnat cu cheia ta: Harmony-v1.0.1-universal.apk.
Testeaza pe telefonul care avea eroarea: FLAC, MP3 cu coperta, album,
anulare si redare cu EQ/ReplayGain. La erori SpotiFLAC foloseste Copy details.
Convertorul nu depinde de codecurile producatorului; descarcarile necesita
in continuare internet, sursa disponibila si autentificarea furnizorului.
Nu a fost certificata functionarea pe toate modelele fizice de telefon.
Verificarile exacte sunt in docs\UNIVERSAL-VERIFICATION.md.

PRIMELE VERIFICARI
- Discovery: Refresh pe All sounds schimba lotul; dupa intoarcerea dintr-un
  album, lotul ramane acelasi. Fara internet functiile online sunt blocate;
  dupa reconectare exista perioada de revenire de 5 secunde.
- Crossfade 12 secunde: testeaza Pause, Shuffle si Repeat All. Pause trebuie
  sa opreasca ambele piese, iar urmatoarea piesa trebuie sa respecte coada.
- Inchide Harmony din aplicatiile recente si redeschide: coada se restaureaza
  fara redare automata. Testeaza Play si dupa oprirea/recrearea serviciului.
- Edit tags: schimba numele, salveaza de doua ori, apoi Undo all edits.
  Verifica titlul in playlist, Favorites si Most played.
- Descarca un album cu melodii selectate; schimba ecranul in timpul descarcarii.
  Verifica notificarea, anularea si reluarea. Verifica stergerea din Library
  si dialogul de pastrare/stergere dupa ascultarea albumului.

Rezultatele auditului, limitele verificarilor si lista detaliata a corecturilor:
   docs\history\AUDIT-v1.4.11.md

Testele de regresie sunt incluse in modulele src\test si tools\audit.
