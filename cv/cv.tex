% ---------- PROJECTS ----------
\section{Projects}

\entry{Harmony --- offline lossless music player (Android, iOS, Windows)}{Kotlin, Jetpack Compose, Swift, C++, Gradle, GitHub Actions}{Sep 2026 -- present}
\begin{itemize}
  \item Built the app solo: \textasciitilde92k lines of Kotlin, \textasciitilde11k Swift and \textasciitilde10k C++ in a multi-module architecture (core, data, domain, feature, playback, sync), 160+ commits and 77 test files; released as v1.0 on all three platforms.
  \item \textbf{Smart Shuffle:} on-device C++ engine that describes every song with a 24-dimensional acoustic profile (octave-band levels, dynamics, pulse) and builds queues from the session ``vibe'', learned transitions and skip feedback, with a self-auditing check and repair step and a live diagnostic HUD.
  \item \textbf{Equalizer engine:} 10-band 32-bit float EQ in C++ at the file's native rate (44.1--384\,kHz), look-ahead limiter, output-aware filtering (speaker, Bluetooth, USB DAC), real-time ``Auto Live'' tonal correction, 60\,fps FFT spectrum and bit-perfect USB mode.
  \item \textbf{Playback:} gapless dual-player crossfade, ReplayGain, self-healing against corrupt frames and decoder failures, Android Auto support.
  \item \textbf{Harmony Connect:} play from the phone on a PC over the local network with pairing, remote control and gap-free queue handoff.
  \item \textbf{Discover \& Downloads:} personalised recommendations, Shazam-based song recognition, album downloads via SpotiFLAC and Soulseek with lossless verification and automatic tags and artwork; repairs mis-encoded Romanian diacritics in legacy tags.
  \item \textbf{Release engineering:} GitHub Actions for Android checks, signed APK releases, Windows (MSIX) and unsigned iOS IPA builds, plus a project website; 135 JUnit tests in the audit suite.
\end{itemize}
