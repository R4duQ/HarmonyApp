# Historical development records

The current public release is **Harmony 1.0.0**, Android version code **83**.

The files here preserve earlier development labels, installation instructions,
audit results and hashes as originally recorded. Those labels are not the
current application version. Historical hashes describe the sources at the time
of that audit, before the public-release relabeling.

For current installation use `../../INSTRUCTIUNI.txt`; for current release notes
use `../RELEASE-v1.0.0-STABLE.md`. Historical instructions may refer to paths at
their former locations; do not use them as current release commands.
